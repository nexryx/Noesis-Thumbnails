# Noesis Thumbnails

Model and texture thumbnails in Windows Explorer, powered by [Noesis](https://www.richwhitehouse.com/noesis/). For Windows 10/11 x64, with Noesis included in the installer.

## Install

Download and run the x64 MSI installer from the project's releases. Switch Explorer to **Large icons** or **Extra large icons**; press **F5** if previews have not appeared yet.

Uninstall via **Settings → Apps → Noesis Thumbnails**.

## Supported formats

**193 extensions**, including:

- **Models:** OBJ, FBX, GLB, glTF, DAE, 3DS, STL, PLY, PSK, MD2, MD3, and IQM.
- **Images and textures:** PNG, JPG, BMP, TGA, DDS, EXR, HDR, BNTX, and more.

See the [full format list](docs/SUPPORTED_FORMATS.md). Compatibility depends on the file variant, required assets, and installed Noesis plugins.
